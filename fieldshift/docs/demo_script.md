# Guion de demo (2 a 3 minutos)

> Pendiente: se completa en la fase de documentación y demo.

Flujo previsto:

1. Elegir un campo en el mapa.
2. Ajustar las prioridades del productor.
3. Ver el diagnóstico del lote (clima, NDVI, barbechos, pendiente).
4. Comparar las rotaciones y aplicar un escenario seco o de calor.
5. Abrir el detalle de una rotación (las 4 fuentes de evidencia).
6. Exportar el reporte.

Antes del demo: correr `warm_cache` y verificar el banner de datos cacheados o de muestra.
